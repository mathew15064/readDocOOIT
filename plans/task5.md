# Restyle UI to Claude Design System + Polish + New Features

## Goal Description
Replace the current dark theme with Anthropic/Claude's warm editorial design system (cream canvas + coral CTAs + dark product surfaces) and implement the following UI/UX enhancements:
1. Fix unwanted nested scrollbars.
2. Drag tags onto documents (drag & drop).
3. Right‑click context menus on documents, bookmark items, and tags.
4. Clicking a bookmark group name opens a full modal showing **all** items with search, sort, filter, bulk actions.
5. Right‑click on a bookmark item shows a context menu with "Reveal in folder", "Open", "Version history".
6. Web file preview modal for Excel, PDF, images, and text.

The work will be performed in the order: **5.0 → 5.1 → 5.2 → 5.3 → 5.4 → 5.5**, running `npm test` after each sub‑task.
